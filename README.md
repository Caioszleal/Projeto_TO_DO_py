# 📝 To-Do App

Um aplicativo de lista de tarefas desenvolvido com Python + Flask, com foco em organização, produtividade e experiência do usuário.

O projeto foi criado com objetivo de aprendizado em desenvolvimento web full stack utilizando:
- Flask
- SQLite
- HTML
- CSS
- JavaScript

---

# 🚀 Funcionalidades

## ✅ Gerenciamento de tarefas
- Adicionar tarefas
- Editar tarefas
- Excluir tarefas
- Marcar como concluída

---

## 📅 Sistema de prazos
- Definir prazo para tarefas
- Destaque visual para tarefas atrasadas

---

## 🔍 Busca e filtros
### Busca:
- Pesquisar tarefas pelo nome

### Filtros:
- Todas
- Pendentes
- Concluídas
- Atrasadas

---

## 🌙 Dark Mode
- Alternância entre tema claro e escuro
- Preferência salva automaticamente no navegador

---

## 📊 Dashboard simples
Contadores automáticos de:
- Total de tarefas
- Pendentes
- Concluídas
- Atrasadas

---

## 📱 Responsividade
Interface adaptada para:
- Celulares
- Tablets
- Desktop

---

# 🛠 Tecnologias utilizadas

## Backend
- Python
- Flask
- SQLite

## Frontend
- HTML5
- CSS3
- JavaScript
